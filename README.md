# 时空猪 · 科多兽远征

**当前版本：v2.10.2**（详见 [CHANGELOG.md](./CHANGELOG.md)；游戏内登录页与帮助面板也可查看更新日志）

一个**纯前端单机动作 RPG**，核心是**刷装备养成**：在**藏身处**里整备，通过时空传送门进出四个生物群系的地下城，刷怪掉装备，比较词条、强化重铸、穿更强的装备，再往更深一层推。

- **零依赖、零构建**：双击 `dist/时空猪.html` 即可开玩，不需要服务器、不需要联网。
- **战斗场景由代码绘制**（Canvas 2D），装备/怪物像素图标内嵌于单文件；**音效由 WebAudio 实时合成**。
- **原创实现**：题材与玩法类型参考了同类网页游戏，但代码、数值、美术、文案均为独立创作，未复制任何第三方站点的素材或代码。

> 关于参考站点：本项目**没有**使用、也没有尝试使用任何第三方站点的账号凭据。所有系统都是依据公开可见的玩法要素重新设计的。

## 快速开始

```powershell
# 方式一（推荐）：直接双击打开单文件版本
dist\时空猪.html

# 方式二：本地开发服务器（改代码后刷新即可）
npm run dev            # → http://127.0.0.1:4321
```

首次进入可点 **游客试玩** 直接开局，或注册一个本地账号（角色存档保存在浏览器 `localStorage`）。

## 藏身处

枢纽不是一堆面板，而是一块**可以走动的安全区**：帐篷、篝火、铁匠炉、商人摊位和一座时空传送门。

- **WASD 走动**，撞到物件会被挡住；走到 NPC 面前出现高亮环与提示，按 `F` 交互（也可以直接**点击** NPC，小猪会自动走过去并打开界面）。
- **铁匠 · 格罗姆** —— 粉猪铁匠（围裙与锤子），强化、重铸、分解。
- **商人 · 皮皮** —— 粉猪商人（帽与钱袋），补给与神秘装备。
- **时空传送门** —— 选择生物群系与层数出发。
- 其余功能全部收进底部按钮：**背包 `B`** · **传送门 `P`** · **战绩 `V`** · **图鉴 `G`** · **帮助 `H`**，`Esc` 关闭当前面板。
- **图鉴 `G`**：怪物 / 装备 / 传说三册。击败敌人或获得装备后解锁条目；未收录显示为「？？？」。已收录怪物显示像素立绘；副本内首领与传送门也会展示立绘。

**背包面板**把「装备 / 属性 / 背包」三件事放在同一个界面里：左侧是 7 个装备槽与完整属性，右侧是可筛选排序的背包格、一键换装与悬浮词条对比。

## 核心系统

### 装备与词条

7 个部位（武器 / 头盔 / 护甲 / 战靴 / 项链 / 戒指 ×2）、5 个品质（普通 / 精良 / 稀有 / 史诗 / 传说）、17 种词条。

- 每件装备有**基础型号属性**（随物品等级 ilvl 成长）与 **0–5 条随机词条**，条数由品质决定。
- **平坦词条**的数值取「同等级属性基准曲线」的百分比，因此到高等级依然有分量；**百分比词条**给固定区间。
- **部位预算**：每个部位对平坦属性的承载能力不同 —— 首饰定位是百分比属性，不会掷出重甲量级的生命/护甲。
- **传说装备**额外带一条独特效果，由战斗逻辑真实生效；**武器部位**还可抽到专属传说：

| 独特效果 | 部位 | 作用 |
| --- | --- | --- |
| 噬魂 | 任意 | 吸血效果翻倍 |
| 狂怒 | 任意 | 生命低于 40% 时攻击力 +40% |
| 贪婪之心 | 任意 | 金币收益与掉落幸运 +25% |
| 秘宝猎人 | 任意 | 精英怪额外掉落一件装备 |
| 时空回响 | 任意 | 击杀时 12% 概率触发一次小型震击 |
| 疾风 | 任意 | 移动速度 +12%，冲刺冷却减半 |
| 连星 | 武器 | 远程普攻额外射出两发侧弹（55% 伤害） |
| 裂空 | 武器 | 命中时对周围敌人溅射 40% 伤害 |
| 猎杀 | 武器 | 对生命低于 30% 的敌人伤害 +75% |
| 星链 | 武器 | 普攻命中时 35% 连锁打击最近另一敌人 |
| 超载 | 武器 | 技能伤害 +30%，震击冷却缩短 25% |
| 渴血 | 武器 | 击杀回复 5% 最大生命 |
| 开·小领域 | 套装武器 | 普攻叠咒印；按 `2` 展开领域（不进普通传说池） |

### 缚誓远征（联动套装）

商人处用 **alpha-stone（秘宝）** 开启「缚誓匣」获取，**不进普通掉落**。

| 件数 | 效果 |
| --- | --- |
| 2 | 技能伤害 +12%，攻击速度 +6% |
| 4 | 咒印叠加速度翻倍；领域内移速 +10% |
| 6 | 领域初绽眩晕 0.55 秒，领域爆发伤害 +25% |

套装武器「缚誓裁刃」带独特「开·小领域」：普攻叠咒印（最多 5），按 `2` 消耗全部咒印展开领域——范围爆发、减速敌人，并在域内增伤。

### 角色属性

角色属性 **完全由 等级 + 已装备物品 派生**（`SP.deriveCharacter`），没有独立加点：

攻击力 / 生命上限 / 暴击率 / 暴击伤害 / 攻击速度 / 移动速度 / 护甲 / 吸血 / 每秒回复 / 伤害反弹 / 拾取范围 / 金币获取 / 掉落幸运 / 技能伤害 / 冷却缩减。

护甲按 `armor / (armor + 60 + 7×怪物等级)` 减伤（上限 75%），因此深层需要持续堆护甲而不是一次堆满。

### 地下城与掉落

| 生物群系 | 怪物等级基准 | 危害 | 怪物 | 关底首领 |
| --- | --- | --- | --- | --- |
| 科多兽营地 | 1 | 践踏潮（冲锋/精英更多） | 科多兽幼崽 / 冲锋科多兽 / 孢子蝠 | 营地首领·科多兽王 |
| 孢子森林 | 5 | 孢子毒雾（持续毒伤，站立更疼） | 孢子行者 / 荆棘兽 / 孢囊喷吐者 | 森林主宰·孢子树王 |
| 时空洞窟 | 10 | 碎晶坠落（预警后范围伤害） | 晶壳爬虫 / 石像鬼 / 碎晶术士 | 洞窟守卫·时空魔像 |
| 魔兽巢穴 | 16 | 巢穴狂潮（刷怪更快、召唤更多） | 巢穴幼魔 / 噬骨魔 / 毒翼 | 巢穴女王 |

- 每层需要**刷够击杀配额**，随后关底首领出现，击败即通关并解锁更深一层（无尽层数）。
- 怪物等级 `mlvl = 群系基准 + (层数-1)`，**掉落装备的 ilvl 与之挂钩**，越深掉落越好。
- **精英怪**（金色光环，2.8× 生命、1.45× 伤害）与首领必掉装备，首领保底稀有以上；普通怪连续空手会逐次提升掉率。
- 掉落会以**品质色光柱**显示，拾取时在 HUD 弹出提示。

### 难度曲线为什么是次线性的

掉落 ilvl 与怪物等级同步上涨，而玩家攻击力 = 等级 + 装备 + 强化，是**叠加成长**的。如果怪物只按线性变强，越往深层反而越轻松；但 2.0 起用过的**纯二次成长**又走向另一个极端：玩家的生命/攻击是线性的，而**装备 ilvl 只能由已通关层数决定**，两边一旦脱钩，卡关就再也没有出口 —— 实测机器人会死在巢穴第 1 层，装备均等连续 10 局停在 7.6。

因此现在改用**次线性**成长（1.6 次幂，线性项另计），并在第 20 层之后叠加每层 ×1.03 的无尽软上限：

- 深层依然明显吃装备，需要回浅层补强再推进；
- 但"补强"这条路真的走得通 —— 配合掉落保底与分解返还，机器人 70 局能推到**巢穴 42 层**，且在 40 层后开始出现阵亡（54 通关 / 16 阵亡）。

这套基线现在由 `npm run balance` 断言守住：通关率 < 50%、洞窟/巢穴深度不足、平均强化为 0 都会直接报错。

### 铁匠与商店

- **强化**：每级 +7% 全部属性，上限 +12，消耗 pig-coin 与强化石。成本随等级温和线性上升（每级 +8% 基础价），一整套满强化约等于 20~30 局的中期收入。
- **重铸**：保留词条种类、重掷未锁定数值；每件最多锁定 2 条词条（锁定提高消耗）。
- **上锁**：背包或铁匠铺可将装备上锁，防止误分解、出售或被「分解垃圾」清理。
- **换装评分**：一键换装与战力按「下一推进层」怪物等级加权，深层更看重生命/护甲等生存属性。
- **分解 / 批量分解**：装备换成强化石与重铸石，并**按比例返还已投入的强化金币与强化石**；批量分解需二次确认，且自动保护上锁 / 传说 / 史诗 / 更强的装备。
- **神秘商人**：6 alpha-stone 换一件按你当前进度产出的高品质装备；也可以用 pig-coin 直接换强化石 / 重铸石，让两种资源互相补位。
- 三种资源：`pig-coin`（通用，击杀掉落随 mlvl 放大）、`alpha-stone`（首领掉落）、强化石 / 重铸石（分解产出）。

## 已知边界

- **账号是本地演示性质**：密码只做本地散列后存在 `localStorage`，**没有真实鉴权，也没有服务端**；清除浏览器数据即丢失存档。可用帮助面板或藏身处的「导出 / 导入」备份 JSON。请勿在其中使用你在别处用过的真实密码；导出文件含本地密码散列，勿公开分享。
- **无联网多人**：本作是单机游戏。
- **旧版存档会自动迁移**：如果你玩过之前的两版（生存竞技 / 面板枢纽），旧存档里的 pig-coin、alpha-stone、牛排与战绩会保留，旧强化等级折算成强化石与重铸石，最高波次折算成副本进度，并赠送一件起手武器；旧密码依然可用。这条路径在浏览器里写了 20 项断言（含「错误密码必须被拒绝」）。
- HUD 的「延迟 ms」显示的是本机实际帧间隔平滑值（本地渲染延迟），不是网络往返时间。
- 若浏览器在 `file://` 下禁用了本地存储，游戏仍可正常游玩，枢纽顶部会给出「进度不会被保存」的提示。
